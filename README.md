## 🧠 How It Works

```
 ┌──────────┐     ┌──────────────┐     ┌─────────────┐     ┌──────────────┐
 │ Document │ ──▶ │  Processing  │ ──▶ │  AI Engine  │ ──▶ │ Clear Result │
 └──────────┘     └──────────────┘     └─────────────┘     └──────────────┘
    upload          parse & clean       analyse & reason      understand & act
```

1. **Input** — the user provides a document.
2. **Processing** — the content is extracted and prepared.
3. **AI analysis** — the model analyses the text and produces insights.
4. **Output** — results are presented in a simple, readable form.
